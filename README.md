\# CODSOFT Task 1 - Rule-Based Chatbot



\## Project Overview



This project is a simple rule-based chatbot developed using Python as part of the CODSOFT internship.



The chatbot interacts with users through the Command Prompt and provides predefined responses based on keywords and patterns in the user's input.



\## Features



\* Responds to greetings

\* Recognizes the user's name

\* Introduces itself

\* Provides the current date

\* Provides the current time

\* Answers basic Python and programming-related questions

\* Tells a simple joke

\* Provides help to the user

\* Handles unknown questions

\* Allows the user to exit the conversation



\## Technologies Used



\* Python 3

\* Python `datetime` module

\* If-elif-else statements

\* String pattern matching

\* Command Line Interface (CLI)



\## How to Run



1\. Open Command Prompt.

2\. Go to the project folder.

3\. Run the following command:



```bash

python chatbot.py

```



4\. Enter your questions when `You:` appears.

5\. Type `bye` to exit the chatbot.



\## Example Conversation



```text

You: hello

Bot: Hello! Nice to meet you. How can I help you?



You: my name is Adarsh

Bot: Nice to meet you, Adarsh!



You: what is your name

Bot: I am a Rule-Based Chatbot created using Python.



You: tell me a joke

Bot: Why do programmers prefer dark mode?

Bot: Because light attracts bugs!



You: bye

Bot: Goodbye! Have a great day!

```
